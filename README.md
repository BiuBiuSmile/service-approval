# 服務項目核定單（電腦／手機響應式版）


## v9 更新

- 已選取的服務右側會顯示 ✓。
- 再點一次該服務卡片／右側 ✓，即可取消該服務並把「一週次數／服務星期」區塊縮回。
- 取消後會立即同步更新本月核定項目、服務總額、部分負擔與剩餘額度。

這是一個純前端、手機優先的長照服務項目核定單工具。

## 功能

- 身分別：一般戶／中低收入戶／長照低收入戶
- 失能等級：第 2～8 級與對應每月額度
- 搜尋服務代碼或服務名稱
- 加入服務項目並輸入核定單位數
- 自動計算服務總額、部分負擔、剩餘額度
- 超出核定額度時自動提示
- 每次開啟或重新整理網頁都會從全新空白核定單開始，不保留上一筆紀錄
- PWA：部署到 HTTPS 網站後，可加入手機主畫面並快取離線使用

## GitHub Pages 部署

此專案不需要 Node.js、npm 或資料庫，直接使用 GitHub Pages 即可。

1. 在 GitHub 建立新的 repository，例如 `service-approval-mobile`
2. 將本資料夾內全部檔案放到 repository 根目錄
3. GitHub repository → `Settings` → `Pages`
4. `Build and deployment` 選擇 `Deploy from a branch`
5. Branch 選 `main`，資料夾選 `/ (root)`，按 Save
6. 等待 GitHub Pages 部署完成後，即可用手機網址開啟

## 資料儲存說明

目前版本為靜態網站，操作資料只存在於當次開啟的頁面記憶體中。關閉或重新整理頁面後會清空，不會保留上一筆核定紀錄，也不會同步到其他手機或電腦。

如果未來要做到「辦公室電腦輸入後，外出手機可以看到同一個個案核定資料」，就需要另外串接 Firebase、Supabase、Google Sheet API 或其他後端服務。


## v2 更新

- 選取服務項目後，可直接在原服務卡片填寫「一週次數」。
- 填寫或加入服務後不會自動捲動到下方，可繼續選擇其他服務項目。
- 已選項目下方會顯示每週服務次數。


## v3 更新

- 已選服務可同時填寫「一週次數」與「服務星期」。
- 星期以一～日七個按鈕快速點選，適合手機操作。
- 例如：`BA02｜每週 5 次｜一、二、三、四、五`。
- 星期與每週次數分開保存，不會強制互相換算，保留同一天多次服務的彈性。
- 點選星期或填寫次數後仍停留在目前服務清單，不會自動跳到下方。


## v4 計算修正

- 「一週次數」現在會即時換算為預估每月單位數。
- 換算基準：以大月估算，每月約 4.5 週，結果四捨五入為整數單位。
- 例如：每週 3 次 → 預估每月 14 單位；每週 5 次 → 預估每月 23 單位。
- 修改一週次數時，服務總額、預估部分負擔與剩餘額度會立即更新，不需要離開欄位。


## v5 星期自動帶入一週次數

- 點選服務星期後，「一週次數」會自動等於目前已選的星期數。
  - 例如：一、三、五 → 自動顯示 3 次。
  - 例如：一、二、三、四、五 → 自動顯示 5 次。
- 自動帶入後仍可直接手動修改「一週次數」，適用同一天可能服務多次等情況。
- 若之後再次增減星期，會重新依目前勾選的星期數自動帶入。
- 星期變更時，預估每月單位數、服務總額、部分負擔與剩餘額度會同步即時更新。


## v6 大月 4.5 週估算

- 預估每月單位數改為：每週次數 × 約 4.5 週（大月）。
- 畫面提示同步改為「每週次數 × 約 4.5 週（大月）」。
